# Tafsir files

`bn-mukhtasar/` and `en-mukhtasar/` hold **Al-Mukhtasar fi Tafsir al-Quran al-Karim** (Al-Mukhtasar in Interpreting the Noble Quran), issued by the **Tafsir Center for Quranic Studies**, in its Bengali and English translations, as published on **QuranEnc.com**.

One file per surah (`1.json` … `114.json`); each file is a JSON array with one string per ayah. The text is reproduced without modification, addition or deletion, as QuranEnc.com's re-publishing terms require. Taken via the Quranic Universal Library (qul.tarteel.ai) and the open tafsir_api collection (github.com/spa5k/tafsir_api).

Other tafsirs in the app (Ahsanul Bayaan, Abu Bakr Zakaria, Ibn Kathir) are not stored here: they are fetched on demand from the tafsir_api collection and credited to their publishers in the app.
